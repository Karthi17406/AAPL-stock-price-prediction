# AAPL Stock Price Prediction using Machine Learning

A machine learning project that uses historical Apple (AAPL) stock data and technical indicators to predict future stock prices.

## Project Overview

This project explores how machine learning can be used to analyze Apple stock price data and predict future prices based on historical market information.

The model uses different technical indicators and price-based features to identify patterns in the stock data.

## Features

- Historical AAPL stock data analysis
- Feature engineering using technical indicators
- Stock return calculations
- Simple Moving Averages (SMA)
- Exponential Moving Average (EMA)
- Relative Strength Index (RSI)
- Moving Average Convergence Divergence (MACD)
- Volatility analysis
- Volume-based features
- Machine learning-based price prediction
- Prediction results stored for analysis

## Features Used

The model uses features such as:

- Close Price
- 1-minute Return
- 5-minute Return
- 10-minute Return
- 15-minute Return
- SMA 5
- SMA 15
- SMA 30
- EMA 10
- RSI
- MACD
- Volatility
- Volume
